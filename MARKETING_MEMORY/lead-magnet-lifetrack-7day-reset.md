# Lead magnet : 7-day reset template (reprendre un tracking sans culpabilité)

> Format : template imprimable 1 page. Promise : reprendre en 10 minutes,
> même après 3 semaines d'abandon.

## Le protocole (10 minutes, jour 1)

1. **Jeter l'arriéré** : ne rattrapez rien. Aujourd'hui = jour 1, le passé est clos.
2. **3 habitudes max** : une santé, une tête, une œuvre. Pas une de plus.
3. **Cocher binaire** : fait / pas fait. Pas de pourcentages, pas de notes.
4. **Phrase humeur** : 7 mots max le soir (« tendu mais séance faite quand même »).
5. **Jours 2-7 : répéter**, sans changer les règles en cours de semaine.

## Règle d'or
Un jour raté ne casse rien. Deux jours de suite modifient le protocole
(simplifier, pas abandonner). Trois semaines parfaites n'existent pas.
